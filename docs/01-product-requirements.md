# 1. Бүтээгдэхүүний шаардлага

## Зорилго

Монголд амьдардаг ажил хайгчдад байршлын нөхцөл нь тохирох бодит зайны ажлыг олоход тусална. 100 идэвхтэй, давхардалгүй зарын зорилттой; тоонд хүрэхийн тулд улс/ажиллах эрхийн шүүлтүүрийг сулруулахгүй. Ажил олгогчийн шууд баталгаа байхгүй үед eligibility-ийн evidence ба хязгаарыг ил тод харуулна.

## Хэрэглэгч ба одоогийн боломж

| Хэрэглэгч | Боломж | Төлөв |
|---|---|---|
| Ажил хайгч | Хайлт, ангилал, remote region, цалин, компанийн мэдээлэл | Хэрэгжсэн |
| Ажил хайгч | Зар дэлгэрэнгүй, эх сурвалж, гаднын application link | Хэрэгжсэн |
| Ажил хайгч | Монгол/Англи interface | Хэрэгжсэн; зарын агуулга автоматаар орчуулагдахгүй |
| Ажил хайгч | Зар хадгалах, өргөдлийн төлөв | Browser-local MVP; интерактив browser шалгалт хийгдээгүй |
| Ажил хайгч | Шинэ зарын имэйл мэдэгдэл | Төлөвлөсөн; мэдэгдэл илгээхгүй |
| Ажил олгогч | Зар илгээх | Хэрэгжсэн; pending review |
| Админ | 2FA, батлах, засах, устгах | Локал workflow шалгасан |
| Админ | Remotive / WWR импорт | Локал хэрэгжсэн; live Supabase шалгаагүй |
| Оператор | Нийтийн deployment, Search Console | Тохируулаагүй |

## Нийтлэх дүрэм

- Approved, active зар л нийтэд харагдана. Pending detail болон sitemap-д харагдахгүй.
- Worldwide/Mongolia evidence, тайлбарын улсын болон биечлэн ажиллах зөрчил, expiry, эх сурвалжийн reuse нөхцөлийг шалгана.
- APAC эсвэл Remote гэсэн үг дангаараа Mongolia eligibility биш.
- Цалин байхгүй бол заагаагүй гэж харуулна. Тогтсон шөнийн цагийг нуухгүй.
- Эх сурвалжийн шаардлагаар нэр ба original URL хадгална; application process-ийг манай сайт хийдэг мэт харагдуулахгүй.
- Talent pools, general applications, давхардсан эсвэл зохиомол заруудыг 100 бодит зарын тоонд оруулахгүй.

## Хүлээн авах шалгуур

Хосолсон хайлт зөв ажиллах; pending/inactive зар нуугдах; аюултай application URL татгалзах; unauthorized mutation 403; ажил олгогчийн илгээсэн зар шууд нийтлэгдэхгүй; 390px дэлгэцэд гол үйлдэл ашиглагдах; source credit харагдах; membership storage failure хэрэглэгчид мэдэгдэх.

Төлбөртэй membership, хэрэглэгчийн account, CV хадгалалт, cross-device sync болон automated alerts нь одоогийн MVP-д орохгүй. Нэмэхдээ authentication, privacy/retention болон бодит delivery шалгалт шаардана.
