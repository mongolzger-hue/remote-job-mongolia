# 4. Дизайны заавар

## Чиглэл

Professional, тайван job board. We Work Remotely-оос мэдээллийн ойлгомжтой байдлаар санаа авсан боловч original logo, layout, өнгө ашиглана. Хайлт, ажлын мэдээлэл болон apply үйлдэл үндсэн фокус; admin technical details хэрэглэгчийн гол урсгалд орохгүй.

## Одоогийн visual system

Ink `#14213d`, muted `#68768c`, primary blue `#2860ef`, border `#e4e9f1`, surface `#f7f9fc`. System Arial/Helvetica sans-serif; 1184px max shell, desktop 32px gutter, mobile 20px. Кардууд 7–14px radius; цэвэр border, бага shadow. Өнгөт company initials нь лого биш; source logos ашиглахгүй.

Headline → supporting text → form/action гэсэн hierarchy. Featured cards, compact company/salary metadata, category chips. Membership benefit cards нь Available/Coming soon статусыг текстээр ялгана.

## Responsive ба accessibility

640px болон 900px breakpoints; mobile form single-column, employer banner vertical, featured cards дотроо scroll. Membership benefits mobile single-column; controls wrap. Document-wide horizontal overflow байж болохгүй.

Semantic heading order, label-тай form controls, keyboard focus-visible outline, status/error текст. Icon нь text label орлохгүй. Status зөвхөн өнгөөр ялгагдахгүй. Монгол урт текст, salary болон company names overflow үүсгэхгүй.

## Copy дүрэм

Монгол/Англи UI утга нэгтэй. Job content эх хэлээрээ. Salary байхгүй үед зохиохгүй; “Verified” болон “100 jobs” badge-ийг бодит evidence/тоогүйгээр тавихгүй. Eligibility нь source requirements-оор шүүсэн, employer guarantee биш гэдгийг дэлгэрэнгүйд харуулна.

## QA

Desktop/mobile homepage, filters, detail, posting, admin, membership болон хоёр хэлний screenshot review. Өмнөх homepage mobile review хийгдсэн; membership-ийн шинэ interactive/responsive browser review хүлээгдэж байгаа.
